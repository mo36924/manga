# 制作メモ：31〜35ページ

- 原作：吉川英治『宮本武蔵』「地の巻」「毒茸」四。
- 原文：[青空文庫 XHTML](https://www.aozora.gr.jp/cards/001562/files/52396_49781.html)
- 30ページ目の帰宅の翌朝から、お甲が又八の帰郷に冷たく答える場面まで。
- 画像生成：imagegen スキルの組み込み image_gen。references/characters.png を人物と絵柄の参照に使用。
- 新しいコマ割り・演出の指示を各生成プロンプトに反映。ページごとに構成を変え、手元・物・視線・人物間の距離・無言の間を使う。
- 既存ページのコマ配置を参照画像から引き継がないよう、画像生成の参照には人物設定画だけを使う。
- AGENTS.md に従い、画像にページ番号を入れない。PDFは作成しない。
- 出力：pages/page-31.png〜page-35.png。使用プロンプト：production/prompts/page-31.txt〜page-35.txt。
- コマは右から左へ読む。セリフは漫画向けの短い翻案。夕べの会話を一続きの場面にまとめる。
- 木剣：四尺ほどの黒樫、緩い反り、木目のある暗褐色、鍔や鞘のない木製の柄。32ページ目に初めて武蔵の手に渡る。
- 又八への贈り物：赤褐色の瑪瑙玉がついた茶色の革巾着。
- 31〜33ページは昼、34〜35ページは夕べの炉端。朱実の鈴や衣装、人物の顔と体格を継承する。
