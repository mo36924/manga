# 宮本武蔵 — 地の巻

日本語フルカラー漫画の1〜50ページです。今回は46〜50ページを追加し、50ページで制作を区切っています。

今回の追加分：[46ページ](pages/page-46.png)／[47ページ](pages/page-47.png)／[48ページ](pages/page-48.png)／[49ページ](pages/page-49.png)／[50ページ](pages/page-50.png)

原作冒頭の関ヶ原での敗戦から、「おとし櫛」の辻風典馬との戦いと夜の帰還までを収録しています。46〜50ページでは、辻風の挑発、煙の中での突入、武蔵との組み合い、野への追跡、又八との合流を描きます。各ページのコマは右から左へ読みます。

46〜50ページは、場面に応じて枠を開き、突入や投げの勢い、月下の野の広がりをページ端まで見せています。白いコマ間の余白を動きに合わせて変え、挑発を受ける沈黙から激しい攻防、決着後の静かな帰り道へ緩急をつけています。

21〜50ページの画像にはページ番号を入れていません。26〜50ページはPNG画像で保存し、PDFは作成していません。

## 原作

吉川英治『宮本武蔵』「地の巻」「鈴」一〜五、「毒茸」一〜六、「おとし櫛」一〜三を原作とし、漫画向けに会話と説明を短く再構成しています。

- [青空文庫・原文](https://www.aozora.gr.jp/cards/001562/files/52396_49781.html)
- [青空文庫・図書カード](https://www.aozora.gr.jp/cards/001562/card52396.html)

底本：『宮本武蔵（一）』吉川英治歴史時代文庫、講談社。青空文庫入力：門田裕志、校正：仙酔ゑびす。
