# 宮本武蔵 — 地の巻

日本語フルカラー漫画の1〜35ページです。今回は31〜35ページを追加し、35ページで制作を区切っています。

今回の追加分：[31ページ](pages/page-31.png)／[32ページ](pages/page-32.png)／[33ページ](pages/page-33.png)／[34ページ](pages/page-34.png)／[35ページ](pages/page-35.png)

原作冒頭の関ヶ原での敗戦から、「毒茸」の炉端での帰郷の話までを収録しています。31〜35ページでは、お甲の隠し物を天井裏へ運ぶ二人、黒樫の木剣を手にした武蔵、又八の帰郷に冷たく答えるお甲を描きます。各ページのコマは右から左へ読みます。

31〜35ページは、慌ただしさを出す小コマ、木剣との出会いを見せる縦の大コマ、視線を追う小コマ、距離と沈黙を描く横の大コマで緩急をつけています。

21〜35ページの画像にはページ番号を入れていません。26〜35ページはPNG画像で保存し、PDFは作成していません。

## 原作

吉川英治『宮本武蔵』「地の巻」「鈴」一〜五と「毒茸」一〜四を原作とし、漫画向けに会話と説明を短く再構成しています。

- [青空文庫・原文](https://www.aozora.gr.jp/cards/001562/files/52396_49781.html)
- [青空文庫・図書カード](https://www.aozora.gr.jp/cards/001562/card52396.html)

底本：『宮本武蔵（一）』吉川英治歴史時代文庫、講談社。青空文庫入力：門田裕志、校正：仙酔ゑびす。
