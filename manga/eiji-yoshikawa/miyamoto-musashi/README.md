# 宮本武蔵 — 地の巻

日本語フルカラー漫画の1〜25ページです。今回は21〜25ページを追加し、25ページで制作を区切っています。

- [今回の確認用PDF（21〜25ページ・全5ページ）](output/pdf/miyamoto-musashi-021-025.pdf)
- [冒頭の確認用PDF（1〜20ページ）](output/pdf/miyamoto-musashi-001-020.pdf)

原作冒頭の関ヶ原での敗戦から、「毒茸」冒頭の松林での出会いまでを収録しています。21〜25ページでは、回復した二人が母屋に移り、朱実と武蔵が茸採りに出かけます。各ページのコマは右から左へ読みます。

21〜25ページの画像とPDF本文にはページ番号を入れていません。番号はファイル名やPDFのしおりなど、管理・移動用の情報に用いています。

## 原作

吉川英治『宮本武蔵』「地の巻」「鈴」一〜五と「毒茸」一〜二の冒頭を原作とし、漫画向けに会話と説明を短く再構成しています。

- [青空文庫・原文](https://www.aozora.gr.jp/cards/001562/files/52396_49781.html)
- [青空文庫・図書カード](https://www.aozora.gr.jp/cards/001562/card52396.html)

底本：『宮本武蔵（一）』吉川英治歴史時代文庫、講談社。青空文庫入力：門田裕志、校正：仙酔ゑびす。
